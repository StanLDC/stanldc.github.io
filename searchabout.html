About

Welcome to LDC Search!

I made this for a bit of fun and to use for myself as a new tab screen for chrome but if you want to use this feel free :D

This website essentially just forwards the text you input into the search box to google.com/search?q=

I’ve also added some cool colour and image background options to choose from for some customisation. I will eventually add more and maybe a feature to pick a custom hex colour but I haven’t got around to that quite yet. I did implement local storage so your colour preferences stay when reloading the site so you don’t have to change it again.

For this website I did use some artificial intelligence for the things that I wasn’t quite sure on how to make. If you are questioning the security of this site and your searches, please do look through as much of the code as you want and tell me if there are any issues. If you do end up finding any issues please contact me at contact@stanldc.com and include "Search Engine" in the subject. I will try to fix them as quickly as I can. You are not obliged to use this so please use this at your own risk and only put as much information as you are willing to input into the search box.
